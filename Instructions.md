================================================================================
                         PDF MARGIN TOOL - USER GUIDE
================================================================================

WHAT IT DOES:
The PDF Margin Tool adds white space to the right side of your PDF pages, 
creating room for account team annotations during MLR review.

ACCESS THE TOOL:
https://bh-relevate.github.io/pdf-margin-tool/
(Bookmark this link for easy access)

================================================================================
                              HOW TO USE
================================================================================

STEP 1: UPLOAD YOUR PDF
------------------------
- Drag and drop your PDF file into the upload area, OR
- Click the upload area to browse and select your file
- File will load and show name, size, and page count

STEP 2: CHOOSE MARGIN SETTING
------------------------------
Select one of three options:

  A) TPP/SPP Default (30%)
     - Automatically adds 30% margin to right side
     - Follows standard submission guidelines
     - Use this for most projects

  B) Custom Pixels - RECOMMENDED
     - Enter specific pixel width (example: 375)
     - Use when you have exact requirements
     - Common values: 300-500

  C) Custom Percentage
     - Enter percentage of page width (example: 25)
     - Useful for different page sizes
     - Valid range: 0-100

STEP 3: PROCESS
---------------
1. Click "Process PDF" button
2. Wait while progress bar shows processing (usually 5-30 seconds)
3. File automatically downloads when complete (via prompt)
4. Filename will have "_annotated" added to it

STEP 4: REVIEW & SUBMIT
-----------------------
- Open downloaded PDF to verify margins look correct
- Upload to SharePoint project folder
- Annotate as needed

================================================================================
                           QUICK REFERENCE
================================================================================

COMMON SCENARIOS:

Desktop Screenshots (1440px width)
  → Use: TPP/SPP Default (30%)
  → Result: ~432px right margin

Mobile Screenshots (390px width)
  → Use: TPP/SPP Default (30%)
  → Result: ~117px right margin

Client Requests Specific Width
  → Use: Custom Pixels
  → Enter: Exact pixel amount requested

Multiple Page Sizes in One PDF
  → Use: Custom Percentage
  → Result: Consistent proportional margins

================================================================================
                         FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Is my file uploaded to a server?
A: No! All processing happens in your browser. Files never leave your computer.

Q: What if I make a mistake?
A: Your original file is never modified. Just reprocess it with different 
   settings.

Q: Can I process multiple PDFs at once?
A: Currently one at a time. Process each file separately.

Q: How long does processing take?
A: Small files (1-10 pages): 5-10 seconds
   Large files (50+ pages): 30-60 seconds

Q: What if processing fails?
A: Try refreshing the page and uploading again. If problem continues, contact
   your team lead.

Q: What browsers work?
A: Chrome, Firefox, Safari, Edge (latest versions)

Q: Does this work on iPad/tablet?
A: Yes! Works on any device with a modern browser.

Q: Can I undo the margin?
A: No undo feature, but you always have your original file. Just reprocess
   with different settings if needed.

================================================================================
                              TIPS & TRICKS

================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: Tool won't load or shows error
SOLUTION: Refresh page, try different browser, or clear browser cache

PROBLEM: File won't upload
SOLUTION: Make sure it's a PDF file (not PNG, JPG, etc.)

PROBLEM: Processing takes forever
SOLUTION: Wait a bit longer. Large files can take up to 60 seconds.
          If over 2 minutes, refresh and try again.

PROBLEM: Download doesn't start
SOLUTION: Check browser's download settings/permissions

PROBLEM: Can't find downloaded file
SOLUTION: Check your Downloads folder. Filename has "_annotated" added.

PROBLEM: Wrong margin size
SOLUTION: Process again with correct settings. Original file is unchanged.
